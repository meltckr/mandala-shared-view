# Shared mandala

A view-only snapshot of a personal 3D sanctuary, published with GitHub Pages.
Drag to look around. Pinch or use the zoom buttons to explore. Overview changes the camera.

This repository contains the viewing assets and sanitized visible scene only.
Journal entries, item notes, reference photographs, private service files, and editing APIs are excluded.
The hosted page is public. It requires no sign-in or Tailscale. Search indexing is discouraged.
The private mandala stays on the owner's Mac; updates to this snapshot require a new export and push.
